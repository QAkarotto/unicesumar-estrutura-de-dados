# 08 - Árvores

Exemplo de implementação de árvore binária de busca em C.

Arquivo principal:

- 01_arvore_binaria_busca.c — implementação com inserção, busca, remoção, travessias em ordem, pré-ordem e pós-ordem, além de altura, contagem de nós e liberação de memória.

Compilar:

```bash
gcc -std=c11 -Wall -Wextra -pedantic 08_arvores/01_arvore_binaria_busca.c -o 08_arvores/01_arvore_binaria_busca.exe
```

Executar:

```bash
./08_arvores/01_arvore_binaria_busca.exe
```
