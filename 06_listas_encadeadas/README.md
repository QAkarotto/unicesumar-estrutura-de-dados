# 06 - Listas Encadeadas

Exemplos de implementação de listas encadeadas simples em C.

Arquivo principal:

- `01_lista_encadeada.c` — implementação com operações essenciais: inserir (início/fim), exibir, buscar, remover, inverter, dividir e liberar.

Compilar:

```bash
gcc -std=c11 -Wall -Wextra 06_listas_encadeadas/01_lista_encadeada.c -o 06_listas_encadeadas/01_lista_encadeada.exe
```

Executar:

```bash
./06_listas_encadeadas/01_lista_encadeada.exe
```
