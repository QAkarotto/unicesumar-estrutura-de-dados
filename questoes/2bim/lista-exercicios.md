# Lista de Exercícios - 2º Bimestre

Material de estudo para a prova da disciplina de Estrutura de Dados.

## Questões

1. O que acontece se uma função recursiva não atingir a sua condição de parada (caso base)?

2. Qual estrutura é acionada na memória para controlar as chamadas de uma função recursiva?

3. O que acontece na fase de retorno de uma recursão após o caso base ser atingido?

4. Como os elementos são conectados em uma lista simplesmente encadeada?

5. Qual é a principal vantagem estrutural da alocação dinâmica (listas) em relação à estática?

6. O que armazena o ponteiro "próximo" de um nó em uma lista simplesmente encadeada?

7. O que diferencia estruturalmente uma Lista Circular das demais listas encadeadas?

8. Como identificamos a condição de parada ao percorrer uma Lista Circular a partir do seu primeiro elemento?

9. O que ocorre se o ponteiro de um "Nó A" apontar para um novo "Nó C" antes de "C" ser conectado ao restante da lista ("Nó B")?

10. Qual é a principal limitação superada pela implementação de uma Lista Duplamente Encadeada?

11. O que cada nó de uma Lista Duplamente Encadeada precisa armazenar obrigatoriamente?

12. Por que inserir dados no início de uma grande Lista Encadeada é mais rápido do que em um Vetor?

13. O que faz uma "Função Hash" ao receber um novo dado do usuário?

14. De onde provém a eficiência no acesso aos dados armazenados dentro de uma Tabela Hash?

15. Qual é o objetivo primordial da utilização de uma Tabela Hash?

16. Como a Tabela Hash localiza um elemento mais rapidamente que um Vetor não ordenado?

17. Como a estratégia de Encadeamento Separado (Chaining) lida com colisões nas Tabelas Hash?

18. Qual foi a principal motivação para a utilização de estruturas em Árvores?

19. O que é um "Nó Raiz"?

20. Como definimos um "Nó Folha"?

21. O que é uma "Subárvore"?

22. O que o "Grau de um nó" representa?

23. O que mede a "Altura de uma árvore"?

24. O que difere fundamentalmente uma Árvore Binária comum de uma Árvore Binária de Busca (BST)?

25. Do que depende o bom desempenho nas buscas em uma Árvore Binária de Busca (BST)?

26. Qual é a ordem do método de Percurso em Pré-Ordem?

27. Qual é a ordem do método de Percurso em Pós-Ordem?

28. Qual método de visitação dita as diretrizes do Percurso em Largura?

29. Qual é o resultado natural proporcionado pelo Percurso Em-Ordem (Esquerda, Raiz, Direita) em uma BST?

30. Como ficaria estruturada uma BST inicialmente vazia se ela recebesse seguidas inserções em ordem decrescente (ex: 50, 40, 30, 20, 10)?
